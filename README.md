# SortVision

An intelligent automatic sorting system that combines **Computer Vision** and **Robotics** to work as a **returns management system** for factories.

## Overview

The system identifies items by their shape and color, classifies them into predefined categories, and sorts them automatically. It tracks each category in real time and notifies management when action is needed.

## How It Works

1. **Detection and Classification:** A camera and computer vision algorithms analyze each item's shape and color, then classify it into one of several categories.
2. **Automatic Sorting:** A robotic mechanism places each item in the bin assigned to its category.
3. **Real-Time Counting:** Each category has its own counter, displayed on a seven-segment display.
4. **Alert and Notification:** When a counter reaches its preset limit, the system triggers an alarm to empty the bin and sends an automatic email to the manager reporting the returned quantity.

## Key Benefits

- Reduces manual labor and human error
- Improves sorting speed and accuracy
- Provides instant tracking of returned items
- Enables timely, data-driven decisions
